## Project Overview

**Goals**

Create a web and mobile `D2` rendering solution so that it can easily be compiled and built into web services and applications to allow live visualisation in documentation (web), and to be able to open `D2` files and create and modify them on `Android` devices.

`D2` rendering as a core part of the auto documentation generation there is a need to have a solution that allows adding this capability to the web. 

The objective is to be able to make diagrammatic interface for resource generation, or resource derived diagram generation.

# Project Management Overview

## Overview

All projects are either active, inactive or completed.

All tasks are store in a kanban for a project. A project can be divided into small programs by using the project identifier and adding a number to notate it is part of a larger project.

All tasks are either inactive, active or completed in the Kanbans. 

## Morphisms

When a project moves backwards (Completed -> Inactive/Active, Active -> Inactive) at the top of that section.
When a project moves forward, it is appended to the end of that section.

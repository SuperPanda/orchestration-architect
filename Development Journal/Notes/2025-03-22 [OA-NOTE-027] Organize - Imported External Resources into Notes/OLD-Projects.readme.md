# Projects README.md
> [!IMPORTANT]
> Projects



Projects are defined and managed within `<DOCMENTS WORKTREE>/Projects/PROJECT_SUMMARY.md`. Projects are either *active*, *inactive* or *concluded* (meaning completed or cancelled).

## Usage 

If lost, the project overview will separate the different contexts based on the header.


```
# Projects SUMMARY

## Active 

[**PROJ_UNIQUE_SHORT_LABEL** Name of project](Kanbans/PROJ_UNIQUE_SHORT_LABEL.md)

## Inactive 

[**ANOTHER_PROJ_UNIQUE_SHORT_LABEL** Name of project](Kanban/ANOTHER_PROJ_UNIQUE_SHORT_LABEL)

## Concluded

[**AGAIN_PROJ_UNIQUE_SHORT_LABEL** Name of project](Kanban/AGAIN_PROJ_UNIQUE_SHORT_LABEL)

```

All tasks are store in a kanban for a project. A project can be divided into small programs by using the project identifier and adding a number to notate it is part of a larger project.

All tasks are either inactive, active or completed in the Kanbans. 

## Morphisms

When a project moves backwards (Done -> Inactive/Active, Active -> Inactive) `prepended to` section.

When a project moves forward, it is appended to the end of that section.

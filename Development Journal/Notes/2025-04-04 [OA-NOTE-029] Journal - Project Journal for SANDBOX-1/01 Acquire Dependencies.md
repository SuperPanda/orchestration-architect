#  Dependencies for the Knowledge Management Experiment

## ESCO Data 

**Structured Taxonomy for Skills/Occupations**

Machine-readable ontology of 13,485 skills/3,082 occuprations.

**Source**: `https://esco.ec.europa.eu/en`



## DGraph

**Native Graph Databse with DQL

- Stores knowledge graph with microsecond level traverals

- Schema-first design

**Source**: `https://docs.hypermode.com/`


### Installation

**Static Binary**

    curl https://get.dgraph.io -sSf | bash

## Go 

**Statically Typed Systems Language**

Good at concurrency.

**Source**: https://go.dev/dl/

### Installation 

sudo pacman -S go


## ELM

**Pure Functional Frontend**

- Type-safe UI with no runtime exceptions

- Compiles to JS with 0 dependencies 

**Source**: `https://elm-lang-org`

### Installation 

#### Binary Installation 

    curl -L -o elm.gz https://github.com/elm/compiler/releases/download/0.19.1/binaries-for-linux.tar.gz
    tar xzf elm.gz

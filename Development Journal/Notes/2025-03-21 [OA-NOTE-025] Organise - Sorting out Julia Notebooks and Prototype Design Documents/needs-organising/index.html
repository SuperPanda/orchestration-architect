Steps:

1. Create a requirements document `Development Journal/Requirements/<YYYY-MM-DD> <Slug>.md`  (a document resource «oa-document:requirement».

    > **Task:**
    > Create cli tool which allows for `oa requirement elicit`, which creates a new document with the status of elicitation

2. List problems and use this to identifies objectives, goals and other things to address the problems, refer to the specification at «oa-specs:oa-document:requirement»

3. Use tools or specialised AI tool to make sure it matches the specification.

4. Now use the document status to analysis using `oa requirement analyze` which will create study notes so some research can be done.

5. When enough research is done, and requirements are listed in the document, and any other notes, ideas, and tasks that come up is finalised run the `oa requirement complete`

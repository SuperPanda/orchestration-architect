# Experiment: Improve Alignment of Visions

## Terminology

VABE: Values, Assumptions, Beliefs and Expectations.

## Discussion

Marvin Minksky's 'The Emotion Machine' discusses multiple levels of think.

DeepSeek is demonstrating great reflection abilities.

Self-reflection is the next step. Can I construct a process that the different elements
are able to reflect on their impact.

Can I generate an agent that can modify its VABEs to achieve my vision?

** Considerations **

The values and visions may be flawed.
Therefore the goal should be to make a process that can improve alignment, as VABEs change.

# Literate Specification User Guide
**Tags**: #LIT_SPEC #UserGuide #literate-programming #literate-writing #literate 
## Synopsis

Use the [LIT_SPEC Literate Spec Template](../Reference Guide/Specifications/LIT_SPEC Literate Spec Template.md) file as a markdown file, and follow the internal instructions.

In summary:

* Copy file  
* Adjust the **Literate Spec Template** part of **`LIT_SPEC Literate Spec Template.md`**, and rename all instances 
  of **`LIT_SPEC_TEMPLATE`**  to whatever you named it. So **`LIT_SPEC Hello World.md`** would global replace **LIT_SPEC_TEMPLATE** to **Hello World** when using the template.

**See template for instructions on:**
* How to use embedded development tooling `:lua` to  load key bind to trigger execution of **Literate Spec**.
* How to use executable blocks.
* How to use the `get_literate_codeblock` and `run_command` inbuilt function.
